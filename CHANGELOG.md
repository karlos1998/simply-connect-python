# Changelog

## 0.1.0 - 2026-09-27

- Add typed synchronous and asynchronous External API clients.
- Add SMS endpoint discovery, idempotent SMS sending, message history and details.
- Add contact and call read APIs.
- Add outbound IVR queue discovery, submission, and inspection.
- Add explicit Problem Details errors and unknown-outcome recovery keys.
- Support Python 3.11 through 3.14.
